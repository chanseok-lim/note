# Inroduction
Topological Data Analysis (TDA)を勉強したのでノートにまとめる。
このノートにおけるゴールはTDAでよく用いられるパーシステント図（persistence diagram）を読み解けるようになることに置く。
具体的には
  1. セル単体、チェイン複体等のホモロジーの基礎的な概念
  2. パーシステントホモロジーの構造定理
  3. 劣位集合フィルトレーションに関する安定性定理

の３つを理解することを目指す。
構成としては前半にホモロジーの基礎、後半にパーシステントホモロジーを置いた。
また群論についての基礎事項についても後ろに章を設けたので、適宜参照してもらいたい。
